# リンクまとめ｜申し込み前の確認ノート

SNSのプロフィールから、自前の確認ガイドへ案内するための1ページです。

- 公開URL: https://ats-business-hub.github.io/links/
- このページにはアフィリエイト（A8・バリューコマースなど）のリンクを置きません。各サイトの記事への通常リンクだけです。
- 先頭にPR（広告を含む旨）を書いています。行き先の記事には広告リンクが含まれることがあります。
- 流入元の区別はクエリで行います。例: `https://ats-business-hub.github.io/links/?from=tiktok`
- ページを `?from=` 付きで開くと、各記事へのリンクにも同じパラメータが付きます。

`ats-business-hub.github.io` 本体と `-ats-business-hub` はこのリポジトリから変更しません。
